# Modal & Image Demo

A minimal, standalone React Native / Expo project created to demonstrate the core `Modal` component rendering an `Image` with simple default styles and components.

## Features

- **Standard `Modal`**: Uses React Native's built-in `Modal` with slide animation and transparent background.
- **Rendered `Image`**: Displays a local image asset using the native `Image` component.
- **Default Components**: Uses standard `Button`, `Text`, and `View` without complex styling or heavy third-party libraries.

## How to Run

1. Open your terminal in this directory:
   ```bash
   cd modal-image-demo
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Press:
   - `a` to open on Android emulator or connected device
   - `w` to open in the web browser
   - Scan the QR code with the Expo Go app on your phone
